Cara Menjalankan Dashboard

### 1. Clone Repository

```bash
git clone https://github.com/23430001alifya/dashboard-e-commercee.git
cd NAMA-REPO
```

---

### 2. Install Library

Pastikan sudah menginstall Python (versi 3.8 ke atas), lalu jalankan:

```bash
pip install -r requirements.txt
```

---

### 3. Jalankan Dashboard

Masuk ke folder dashboard:

```bash
cd dashboard
streamlit run dashboard.py
```

---

### 4. Buka di Browser

Setelah dijalankan, dashboard akan otomatis terbuka di browser pada alamat:

```
http://localhost:8501
```

Dashboard ini dapat dijalankan secara online menggunakan Streamlit Cloud:
(https://dashboard-e-commerceegit-alifyadinda.streamlit.app/)
